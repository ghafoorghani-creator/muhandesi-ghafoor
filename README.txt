# مهندسی غفور
نسخه HTML آزمایشی موبایل‌پسند.
## اجرا در GitHub Pages
1. فایل‌های `index.html` و `icon.png` را در ریشه repository آپلود کنید.
2. Settings → Pages → Deploy from branch → شاخه main و پوشه /(root) را انتخاب کنید.
3. لینک سایت را در Safari آیفون باز کنید؛ Share → Add to Home Screen.
## محدودیت‌های مهم
- خروجی DXF شماتیک است و در AutoCAD باز می‌شود؛ DWG بومی صادر نمی‌کند.
- ورود DWG و ویرایش کامل CAD، اندازه‌گیری متریک واقعی با دوربین، و تبدیل دقیق تقویم شمسی به کتابخانه/سرویس تخصصی نیاز دارند.
- پلان‌ها برای ایده و پیش‌نمایش هستند، نه نقشه اجرایی یا تأییدیه ساختمانی.
