مهندسی غفور — نسخه به‌روزشده

نصب به شکل اپ مستقل روی آیفون:
1) فایل‌های index.html، icon.png، manifest.json و sw.js را در ریشهٔ repository گیت‌هاب آپلود کنید.
2) Settings → Pages → Deploy from a branch → شاخه main و پوشه /(root) را انتخاب کنید.
3) سایت HTTPS را یک بار در Safari باز کنید، Share → Add to Home Screen را بزنید و اگر گزینه Open as Web App بود فعال کنید.
4) بعد از نصب، از آیکن صفحه اصلی باز کنید؛ در حالت standalone نوار آدرس Safari دیده نمی‌شود. وب‌اپ همچنان از موتور وب iOS استفاده می‌کند.

ترسیم پلان‌ها اکنون اندازهٔ کلی زمین و ابعاد ورودی‌شدهٔ هر اتاق را نمایش می‌دهد؛ خروجی DXF نیز برچسب‌های اندازه دارد. چیدمان اتاق‌ها هنوز شماتیک است و نقشهٔ اجرایی حرفه‌ای محسوب نمی‌شود. برای ساخت دقیق، محوربندی، موقعیت دروازه و کلکین، سازه و نورم‌های محل باید توسط متخصص تکمیل و بررسی شود.
